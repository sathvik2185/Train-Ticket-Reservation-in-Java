# Train Ticket Reservation in Java

A Java-based Train Ticket Reservation System designed to simplify train ticket booking and management. Users can reserve seats, view ticket details, cancel bookings, and check seat availability through an interactive menu-driven interface.

## 📌 Features

* Book train tickets
* Enter and manage passenger details
* Check seat availability
* View reservation details
* Generate ticket information
* Cancel existing reservations
* Simple menu-driven interface
* User-friendly console interaction

## 🛠️ Technologies Used

* **Java**
* **Object-Oriented Programming (OOP)**
* **Java Scanner Class**
* **Array / ArrayList**
* **Conditional Statements**
* **Loops and Methods**

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Train-Ticket-Reservation-in-Java.git
```

2. Open the project in **VS Code, IntelliJ IDEA, Eclipse**, or another Java-supported IDE.

3. Compile the program:

```bash
javac TrainTicketReservation.java
```

4. Run the application:

```bash
java TrainTicketReservation
```
